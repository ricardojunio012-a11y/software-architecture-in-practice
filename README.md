# Software Architecture in Practice: lab code

Lab code for the book *Software Architecture in Practice*, by Ricardo Júnio Gonçalves Filho (In Practice collection).

Each chapter has its own folder in `code/chNN/`, with a `README.md` that walks through the lab. The labs run with Docker and Docker Compose; Appendix A of the book explains how to set up the environment.

This repository has the labs of Volume 1 (chapters 1 to 14) and Volume 2 (chapters 15 to 30).

Found a mistake in the book or the code? Open an issue or write to ricardojunio012@gmail.com.
